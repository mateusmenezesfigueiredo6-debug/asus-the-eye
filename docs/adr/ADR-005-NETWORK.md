# ADR-005 — Network progression and finality

Status: proposed beyond local.

Anvil 31337 is local; Base Sepolia 84532 is the only example staging network; Base
Mainnet 8453 is disabled and not preselected for production. Chain ID, bytecode/address,
confirmations, RPC diversity and reorg handling are verified per receipt. Every broadcast
is manually gated; no promotion is automatic.
