# AS 30 MELHORES SKILLS E FERRAMENTAS MCP PARA O VERTICAL CANNABIS

Inventario das capacidades disponiveis nas sessoes Claude deste projeto,
ranqueadas por utilidade para o vertical. "Skill" = pacote de instrucoes
invocavel; "MCP" = servidor de ferramentas conectado a conta.

  WhatsApp somente pela API oficial do Business.
- Supabase e Cloudflare criam custo real ao provisionar; provisionar so
  com decisao do dono.
- A lista reflete a sessao de 24/08/2026; servidores MCP conectados podem
  variar por sessao.
